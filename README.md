# 고양이를 찾아서 (A Monochrome Maze)

흑백 픽셀로만 그려지는 탐색 공포 게임.
산책 중 도망친 고양이를 찾아 밤의 공원에서 골목으로, 낡은 건물로, 지하로 내려간다.

브라우저만 있으면 되는 웹앱이다. 빌드 도구도, 외부 에셋도, 네트워크도 필요 없다.

## 실행

`index.html` 을 브라우저로 열면 끝이다. 로컬 서버로 띄우고 싶다면:

```bash
python -m http.server 8777
# http://localhost:8777
```

시작 화면에서 아무 키나 누르면 오디오가 켜지고 도입 연출이 시작된다.
**소리를 켜고 플레이할 것** — 분위기의 절반이 사운드다.

## 조작

| | PC | 휴대폰 (가로) |
|---|---|---|
| 이동 | `W A S D` / 방향키 | 왼쪽 절반을 끌기 — 민 정도만큼 속도가 붙는다 |
| 열기 · 뒤지기 | `E` | 오른쪽 절반 또는 `E` 버튼 |
| 연출 건너뛰기 | `Space` | `E` |
| 다시 시작 | `R` | `E` |

휴대폰은 **가로모드 전용**이다. 세로로 들면 돌려 달라는 안내가 뜬다.
첫 터치에서 전체화면으로 들어가고 오디오가 열린다 — iOS 는 제스처 핸들러 안에서만
오디오를 허용하므로 이 타이밍이 중요하다.

`?touch=1` 을 붙이면 PC에서도 휴대폰 조작으로 켤 수 있다(확인용).

## 연출 의도

무서운 것이 튀어나오지 않는다. 점프 스케어도, 귀신도, 추격자도 없다.
공포는 오직 **어둠의 넓이**와 **소리**로만 만든다.

- **화면** — 배경은 검정, 구조물은 흰 픽셀. 480×270 해상도에 6단계 회색을
  8×8 Bayer 오더드 디더로 배분한다. 손전등 반경 밖은 완전한 검정으로 눌러버리고,
  아주 밝은 재질(건물 입면·갓돌)만 겨우 윤곽으로 남는다.
- **소리** — 저역 드론과 바람 위로 6~14초마다 불규칙하게 FM 종소리가 울린다.
  긴 컨볼루션 리버브가 걸려 있어 언제나 "먼 곳에서" 들린다.
- **문** — 구조물로 들어갈 때 피치가 불규칙하게 미끄러지는 끼이익 소리와 마지막 쿵.
  플레이 중에도 20~40초마다 어딘가에서 문이 여닫히는 소리가 희미하게 난다.
- **고양이** — 목표 방향으로 패닝된 야옹 소리가 주기적으로 들린다. 유일한 길잡이다.

## 공간

무작위 미로가 아니다. 네 개의 공간을 직접 구성했고, 각자 다른 재질과 소품을 쓴다.

| | 바닥 | 벽 | 소품 |
|---|---|---|---|
| **공원** | 자갈 산책로 · 연석 · 잔디 | 벽돌 담장 | 가로등(발광) · 나무 · 벤치 · 덤불 · 연못 |
| **골목** | 균열 있는 아스팔트 | 벽돌 건물 입면 + 창문 | 가로등 · 쓰레기통 · 드럼통 · 나무상자 · 팔레트 · 간판 |
| **낡은 건물** | 널마루 | 세로줄 벽지 + 걸레받이 | 침대 · 장 · 탁자 · 의자 · 선반 · 화분 |
| **지하** | 젖은 콘크리트 · 물웅덩이 | 거친 석조 | 보일러 · 드럼통 · 배관 · 선반 · 매달린 전구(발광) |

`js/levels.js` 의 청사진에 직사각형 목록으로 배치를 적어 두었다.
골목은 건물 덩어리 사이의 골목·뒷길·철망으로 막힌 막다른 길, 실내는 복도 두 개와
여덟 개의 방, 지하는 통로로 이어진 여섯 개의 석조 챔버다.

## 구조

```
index.html          진입점 (classic script 로드, 번들러 없음)
css/style.css       캔버스 스케일링 · 내레이션/타이틀 오버레이
js/utils.js         유틸 · Bayer 매트릭스 · 입력 · 내레이터(타이프라이터)
js/audio.js         Web Audio 절차적 사운드 엔진 (드론/종/삐걱/야옹/발소리)
js/renderer.js      Float32 휘도 버퍼 → 광원 → 그레이스케일 디더 소프트웨어 렌더러
js/tiles.js         테마별 16x16 타일 페인터 (바닥/벽/입면/창문/물/잔디/연석)
js/props.js         소품 스프라이트를 절차적으로 그려 캐시
js/levels.js        손으로 구성한 레벨 청사진 + 빌더 · 수색 배치 · 도달 가능성 검사
js/sprites.js       주인공 · 고양이 · 그것 스프라이트
js/touch.js         휴대폰 가로모드 조작 (가상 스틱 + 액션)
js/game.js          씬 상태기계 · 도입 연출 타임라인 · 스테이지 · 수색 · 엔딩
```

내부 해상도는 PC 480×270, 휴대폰 416×234로 시작하고,
처음 3초 평균 프레임이 26ms를 넘으면 352×198로 한 번 더 내린다.
픽셀당 비용이 큰 렌더러라 화면 크기가 곧 프레임 시간이다.

### 렌더링 방식

`Float32Array` 휘도 버퍼에 타일과 소품을 그린 뒤, 픽셀마다 광원 감쇠를 곱하고
Bayer 임계값으로 6단계 회색 중 하나에 확정한다.

```
q = luminance × light × fade + grain          (0 ~ 1)
level = floor(q×5) + (frac(q×5) > bayer8[y%8][x%8] ? 1 : 0)
```

- **광원**은 1/4 해상도 격자에 계산해 이중선형 보간한다. 지하처럼 전구가 여러 개 켜진
  화면에서도 픽셀마다 광원을 전부 도는 비용을 피한다.
- **감쇠**는 `min(1, (1-q)×1.55)` 로, 중심부는 평탄하게 밝고 바깥에서 급히 떨어진다.
  순수 역제곱은 가운데 한 점만 최대치라 화면 전체가 회색으로 눌린다.
- **아주 어두운 값은 검정으로 눌러버린다.** 안 그러면 디더가 빛이 닿지 않는 곳까지
  점무늬로 채워 어둠이 죽는다.
- **벽은 아랫면이 바닥과 닿을 때 "정면(face)"을 그린다.** 위에서 내려다보는 화면에
  입면이 살짝 보이는 방식이고, 이것이 벽 덩어리를 건물로 읽히게 하는 핵심이다.
  건물 입면에는 규칙적으로 창문이 뚫린다.
- **캐릭터와 가구는 실루엣 둘레 1px를 검게 판다.** 밝은 벽·바닥 위에서 묻히지 않도록.

캔버스는 `image-rendering: pixelated` 로 확대되므로 어떤 해상도에서도 픽셀이 뭉개지지 않는다.
프레임당 약 7ms(월드 2ms + 광원·디더 5ms).

## 진행

1. **도입** — 밤 산책. 종이 울리고, 고양이가 귀를 세우고, 가로등이 닿지 않는 곳으로 뛰어든다.
2. **하나 · 골목** — 골목을 향해 난 문을 찾는다.
3. **둘 · 낡은 건물** — 방을 하나씩 지나 지하로 내려가는 문까지.
4. **셋 · 지하** — 마지막 챔버에 고양이가 앉아 있다.
