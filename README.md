# 고양이를 찾아서 (A Monochrome Maze)

흑백 1비트 픽셀로만 그려지는 미로 탐색 공포 게임.
산책 중 도망친 고양이를 찾아 어두운 골목과 건물, 지하를 헤맨다.

브라우저만 있으면 되는 웹앱이다. 빌드 도구도, 외부 에셋도, 네트워크도 필요 없다.

## 실행

`index.html` 을 브라우저로 열면 끝이다. 로컬 서버로 띄우고 싶다면:

```bash
python -m http.server 8777
# http://localhost:8777
```

시작 화면에서 아무 키나 누르면 오디오가 켜지고 도입 연출이 시작된다.
**소리를 켜고 플레이할 것** — 분위기의 절반이 사운드다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` / 방향키 | 이동 |
| `E` | 문 열기 / 고양이 부르기 / 대사 넘기기 |
| `Space` | 도입 연출 건너뛰기 |
| `R` | 엔딩 후 다시 시작 |

## 연출 의도

무서운 것이 튀어나오지 않는다. 점프 스케어도, 귀신도, 추격자도 없다.
공포는 오직 **어둠의 넓이**와 **소리**로만 만든다.

- **화면** — 배경은 순수한 검정, 구조물은 흰 픽셀. 중간톤은 8×8 Bayer 오더드 디더로
  흑/백 두 색으로만 분해된다. 손전등 반경 밖은 미세한 그레인만 남고 완전히 사라진다.
- **소리** — 저역 드론과 바람 위로 6~14초마다 불규칙하게 FM 종소리가 울린다.
  긴 컨볼루션 리버브가 걸려 있어 언제나 "먼 곳에서" 들린다.
- **문** — 구조물로 들어갈 때 피치가 불규칙하게 미끄러지는 끼이익 소리와 마지막 쿵.
  플레이 중에도 20~40초마다 어딘가에서 문이 여닫히는 소리가 희미하게 난다.
- **고양이** — 목표 방향으로 패닝된 야옹 소리가 주기적으로 들린다. 유일한 길잡이다.

## 구조

```
index.html          진입점 (classic script 로드, 번들러 없음)
css/style.css       캔버스 스케일링 · 내레이션/타이틀 오버레이
js/utils.js         유틸 · Bayer 매트릭스 · 입력 · 내레이터(타이프라이터)
js/audio.js         Web Audio 절차적 사운드 엔진 (드론/종/삐걱/야옹/발소리)
js/sprites.js       픽셀 스프라이트 문자열 데이터
js/maze.js          미로 생성(백트래커 + braid + 방) · BFS
js/renderer.js      Float32 휘도 버퍼 → 광원 → 1비트 디더 소프트웨어 렌더러
js/game.js          씬 상태기계 · 도입 연출 타임라인 · 스테이지 · 엔딩
```

### 렌더링 방식

320×180 해상도의 `Float32Array` 휘도 버퍼에 맵과 스프라이트를 그린 뒤,
픽셀마다 광원 감쇠를 곱하고 Bayer 임계값과 비교해 흑 또는 백으로만 확정한다.

```
white  if  luminance × light × fade + grain  >  bayer8[y%8][x%8]
```

캔버스는 `image-rendering: pixelated` 로 확대되므로 어떤 해상도에서도 픽셀이 뭉개지지 않는다.
흰 벽 위에서 캐릭터가 묻히지 않도록, 스프라이트는 실루엣 둘레 1px를 검게 파낸 뒤 그린다.

## 진행

1. **도입** — 밤 산책. 종이 울리고, 고양이가 귀를 세우고, 어둠 속으로 뛰어든다.
2. **하나 · 골목** — 문을 찾아 나간다.
3. **둘 · 낡은 건물** — 더 넓고, 방이 많다.
4. **셋 · 지하** — 고양이가 앉아 있다.

미로는 매 플레이마다 새로 생성된다.
